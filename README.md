# Inspirational Homepage

A beautiful, modern Next.js application that provides daily inspiration, weather updates, goal tracking, and an image gallery to brighten your day.

## Features

- **Daily Inspirational Quotes**: Start your day with motivational quotes
- **Weather Updates**: Stay informed about current weather conditions
- **Goal Tracking**: Set, organize, and track your personal and professional goals
- **Image Gallery**: Browse through beautiful inspirational images
- **Modern UI**: Clean, responsive design with Tailwind CSS

## Tech Stack

- **Next.js**: React framework for server-rendered applications
- **Tailwind CSS**: Utility-first CSS framework for rapid UI development
- **Yarn**: Package manager
- **Local Storage**: For persistent goal tracking
- **External APIs**: Weather, quotes, and image services

## Getting Started

### Prerequisites

- Node.js 14.0 or later
- Yarn package manager

### Installation

1. Clone the repository
```bash
git clone https://github.com/yourusername/inspirational-homepage.git
cd inspirational-homepage
```

2. Install dependencies
```bash
yarn install
```

3. Run the development server
```bash
yarn dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser

## Build for Production

```bash
yarn build
yarn start
```
